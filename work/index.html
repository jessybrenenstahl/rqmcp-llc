Evidence before assurance

“The run ended”
did not mean
“the lesson helped.”

Our own agent project contained a false-credit path: a stopped child could make a lesson look helpful without a recorded work outcome.

We replayed the same five checks on original and corrected source snapshots. The original failed four subtests; the corrected version passed all five methods, while the contrasting valid cases stayed intact.

This is a project self-audit using fixture evidence, not a customer result or proof of generally reliable learning.

Jessy Brenenstahl is the maker of Ultimentality and founder of RQ MCP LLC. The program spans formal and executable semantics, agent memory and orchestration, desktop and phone systems, and interactive fiction.

Its core runs today: Relicquary (v0.9.0), durable, local-first, receipt-bound memory and orchestration for agents. One Rust binary, SQLite and Markdown on your disk, a receipt for every mutation, and your model, local or your own provider. AIM wraps that core in governance; it is a working prototype, and we mark that line rather than blur it. A result only counts when it survives a test it could have failed.

These engagements apply relevant parts of that work to a bounded customer problem. They do not promise a generally self-improving agent. Engineering may be AI-assisted; any agreed human review is performed and recorded.
